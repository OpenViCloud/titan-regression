# Regression plan — mọi case của bộ spec

Mỗi case một ID ổn định (`<MODULE>-NN`); spec mang ID trong tên test (`test('VM-03 stop từ Running', …)`) để report đối chiếu. Thứ tự module và env chạy: [README](README.md). Cột **Nguồn** trỏ luật; người viết spec đọc lại code ở chỗ luật trỏ tới và ghi nguồn vào comment đầu test: file trong repo này ghi `file:line`; repo khác ghi `<repo>:<path>` kèm tên hàm, type, method hoặc test (doc của `OpenViCloud/titan-ops`: ở đây link đầy đủ `https://github.com/OpenViCloud/titan-ops/blob/main/docs/…#anchor`, trong comment spec `OpenViCloud/titan-ops:docs/…#anchor`), **không** số dòng (vd. `OpenViCloud/titan-control-plane:Titan.Host/Program.cs` (`MapHealthChecks("/healthz")`)). Ngoại lệ: ref ghim một commit (`<repo>@<sha>:<path>:<line>`) giữ số dòng. Mỗi ref tự mang repo (và sha nếu ghim): không khai repo một lần cho cả mục hay cả file rồi ghi đường dẫn trần, không viết tắt `:<line>` nối vào ref trước. Ref cũ còn số dòng sang repo khác là rủi ro chấp nhận ([testing §testing-debts](https://github.com/OpenViCloud/titan-ops/blob/main/docs/architecture/testing.md#testing-debts)), sửa khi chạm; — luật đổi mà case không đổi là case sai.

Kỳ vọng chung cho mọi case tạo tài nguyên (không nhắc lại từng dòng):
- Create gửi `Idempotency-Key`, nhận id-only body ([http-contract §create-returns-id](https://github.com/OpenViCloud/titan-ops/blob/main/docs/architecture/http-contract.md#create-returns-id)); poll `GET` tới khi `transition` rỗng và current đạt đích, hạn chờ = 2 chu kỳ reconciler (4 phút) + thời gian lệnh.
- Tài nguyên tạo ra mang tên `rg-<loại>-<lượt>` và được xoá trong `finally`; xoá xong `GET` list không còn nó, `GET` theo id (nếu route giữ hàng) báo existence `Deleted`.
- Lỗi đọc ở `code`, không ở `detail` ([http-contract §error-envelope](https://github.com/OpenViCloud/titan-ops/blob/main/docs/architecture/http-contract.md#error-envelope)).

**(host)** = đọc trên host Incus của cluster (Phase 4 của `release:regression`, lệnh `L-x`).

`beta-user` trong một case là tenant test của lane đang chạy: `beta-user` ở lane a và ở lượt tuần tự, `beta-user-2` ở lane b khi chạy hai lane ([testing §regression-lanes](https://github.com/OpenViCloud/titan-ops/blob/main/docs/architecture/testing.md#regression-lanes)); `smoke` và `cleanup` chạy ở cả hai lane.

## terraform-provider (runner, sau `cleanup` — chỉ staging)

Provider ở repo public `OpenViCloud/terraform-provider-openvicloud`, đo bằng **đúng commit sẽ gắn tag phát hành**: `GOOS=linux GOARCH=<kiến trúc node> CGO_ENABLED=0 go test -c` ở commit đó, agent chép binary vào pod khi spec in `BINARY_WAIT`; spec (`terraform-provider/terraform-provider.spec.ts`) tạo token API `rg-tok-tfp-<lượt>` bằng JWT `beta-user`, chạy `-test.run TestAcc` với `TF_ACC=1`, `OPENVICLOUD_TEST_CLUSTER` = cluster của env (`envOf()`; staging `singapore01`), `OPENVICLOUD_API_URL` = API của env, `OPENVICLOUD_TOKEN` = token đó qua env, rồi xoá token ở `afterAll` — bí mật không rời pod.
